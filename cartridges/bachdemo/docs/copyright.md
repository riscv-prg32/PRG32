# Music and copyright

The musical source is Johann Sebastian Bach's *Prelude in C major*, BWV 846.
Bach died in 1750, so the underlying composition is in the public domain.

This package does not contain a third-party recording, MIDI file, scanned
score, engraving, sound font, or sample. `scripts/generate_audio.py` contains a
newly encoded harmonic outline and generates a compact PRG32 tracker
arrangement. That new code and arrangement data are supplied under the MIT
License included with the project.

When publishing derivatives, do not add a modern edition, performance,
recording, or sample unless its license is independently verified and recorded
in `metadata/colophon.json`.
